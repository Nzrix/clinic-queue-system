# Screenshots

Screenshots will be added here after running the application.

To generate screenshots:
1. Run `docker-compose up --build`
2. Access http://localhost
3. Login with demo/demo123
4. Navigate through each page and capture screenshots
5. Save them in this directory as:
   - dashboard.png
   - patients.png
   - appointments.png
   - queue.png
   - queue-display.png
